# FrameLedger · 影视制作预算与资产版权协同平台

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型影视制作团队，演示预算版本、成本预测、合同里程碑、资产版本、授权窗口冲突与审批审计的协同闭环。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5175，API 默认 `http://localhost:4104`。

## 业务能力

- 项目 / 季 / 交付日期与预算基线；计划、承诺、实际、预测成本四账合一
- 供应商合同额度、付款里程碑与付款暴露额
- 母版、预告、海报、音频、字幕等资产版本和 checksum 登记
- 资产版本谱系：免上传媒体的版本元数据登记、父子关系与变更说明、授权范围 / checksum 对比、送审 / 锁定 / 撤回状态机
- 版本级引用：资产列表、版权冲突、审批单与交付预检均指向具体版本（如 AST-001-V8）而非资产名
- 不可变历史：锁定版本不可覆盖，授权失效以追加事件登记；交付预检按版本号钉死引用，新版本锁定后旧预检标记 stale 而非静默改指针
- 登记健壮性：幂等键去重重试、版本号跳跃 / 并发登记返回 409 与当前头版本、重复 checksum 需显式确认
- 地域、平台、有效期、版权标签冲突检测
- 预算 / 资产 / 交付审批队列和审计事件
- React 控制台支持项目切换、预算表、风险雷达、审批操作、版权资产视图和版本谱系操作台

当前使用内存数据，领域服务按模块设计，后续可替换 PostgreSQL、对象存储、工作流和版权方台账服务。
